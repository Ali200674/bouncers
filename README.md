# Jalapeno Bounce!

![GamePlay](./game.gif)


Description:
- Jalapeno Bounce is a game where you spawn a bunch of jalapenos that bounces off the screen. 
- You can spawn up to 20 per game.
- Each jalapeno starts with a random speed and rotation
- Each time a jalapeno bounces off the screen, its rotaton speed changes
- After six seconds, the jalapeno disappears

Controls: 
- A (X on keyboard (using mGBA), Y on keyboard (using GitHub Actions)): spawns a jalapeno at a random speed and rotation.
- B (Y on keyboard): Gets the average x position of all jalapenos to the console (on mGBA only)
